# Student Course API

A simple read-only REST API for Laboratory Activity 3.

## Endpoints

- GET /api/health
- GET /api/courses
- GET /api/courses/1
- GET /api/courses/9999

## Technology

- Python
- Flask
- JSON

## Description

This API provides five fictional courses through read-only endpoints. It uses a static list of sample data and does not require a database.
